One line about crypto trading life, entered in the make.fun bounty
"Laugh Track: The Crypto Trading Joke Contest".

> "My wallet's so light after a trade, even the blockchain's gas fee feels like a generous tip."

The hook: an emptied wallet reframed — after a bad trade there is so little
left that even the gas fee reads as a generous tip. The punch lands on the
last two words.

## Run it

```sh
node main.ts
```

This validates the line (1–200 characters, a single line, no control
characters) and writes it, plus one trailing newline, to `/output/entry.txt`.
